# 台數規則表（草案）

以業界常見的「標準台灣 16 張麻將公定台數表」為起點整理，供拍照辨識功能未來的自動計台邏輯使用。**這是草案**，數值在不同地區/牌桌間常有出入，請對照你們家實際玩法確認、調整後再列為正式版。

目前 `index.html` 完全沒有台種邏輯（玩家自行輸入 1-20 台的數字），所以這份表格是全新建立，之後可作為自動計台引擎的規則依據，也可以回頭讓「記錄本局」的手動輸入改用勾選台種取代直接輸入數字。

---

## 基本台

| 台種 | 台數 | 說明 |
|------|------|------|
| 門清 | 1台 | 未吃、碰、明槓，全靠自己摸/胡 |
| 自摸 | 1台 | 自己摸牌胡牌（app 已有此欄位，僅差在付款方式不同） |
| 不求人 | 5台 | 門清＋自摸＋無暗槓以外的鳴牌 |
| 全求人 | 1台 | 胡牌前四面都靠吃碰槓組成，只剩將眼未定 |

## 花牌

| 台種 | 台數 | 說明 |
|------|------|------|
| 每張花牌 | 1台/張 | 依花牌數量累加 |
| 正花（花牌花色對應自己座位） | 加1台 | 例：東家配梅/竹（依流派對應表） |
| 八仙過海 | 8台 | 集滿全部 8 張花牌 |

## 特殊胡牌時機

| 台種 | 台數 | 說明 |
|------|------|------|
| 天胡 | 滿貫或固定高台（如32台） | 莊家起手即胡 |
| 地胡 | 滿貫或固定高台（如16台） | 閒家第一巡自摸 |
| 人胡 | 依規則，或不算 | 閒家第一巡放槍胡牌，部分牌桌不採計 |
| 海底撈月 | 1台 | 最後一張牌自摸胡 |
| 河底撈魚 | 1台 | 最後一張棄牌放槍胡 |
| 槓上開花 | 1台 | 加槓/暗槓後補牌自摸胡 |
| 搶槓 | 1台 | 胡別家加槓的牌 |
| 十三么（么九牌） | 滿貫或固定高台 | 十三張么九字牌組合 |

## 尚待確認事項

- [ ] 花牌「正花」對應表是否採用、對應規則為何
- [ ] 天胡/地胡/字一色/大四喜/十三么是否用「滿貫」（直接封頂）還是固定台數
- [ ] 連莊是否額外加台（app 目前只顯示「莊×N」，未計入金額）
- [ ] 單吊/卡張/邊張聽牌是否計台（多數台灣 16 張規則不計，先預設不計）
- [ ] 台數上限（例如全部疊加後是否封頂於某個台數）

> 確認以上項目後，這份表格才會轉為正式版，並用來設計自動計台引擎的資料結構。
